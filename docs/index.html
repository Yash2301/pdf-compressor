Features

Keeps OCR text

Smart mode only recompresses the page images. Searchable text, links and bookmarks stay intact.

Max mode

Turns each page into one optimized image for the smallest possible file.

Batch processing

Add many PDFs or a whole folder and compress them all in one go.

Grayscale option

Convert colour scans to grayscale for an extra size cut on text documents.

Never bigger

If a file can't be made smaller, the original is kept as-is.

Private & offline

No uploads, no accounts, no tracking. Everything runs on your computer.

Install

Windows

  1. Download PDFCompressor-windows.exe.
  2. Double-click to run. No install needed.
  3. If SmartScreen warns you, click More info → Run anyway.

macOS (Apple Silicon)

  1. Download PDFCompressor-mac.zip and unzip it.
  2. Right-click PDFCompressor.app → Open → Open.

From source

Needs Python 3.10+ with Tk.

pip install -r requirements.txt
python app.py
